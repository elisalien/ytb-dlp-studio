================================================================
   yt-dlp Studio  -  Mode d'emploi (Windows)
================================================================

Telechargeur video 4K / 8K et convertisseur local, avec une
interface dans le navigateur. Portable : tout reste dans ce dossier.

----------------------------------------------------------------
 RENARD.mp3 (application de bureau)
----------------------------------------------------------------

RENARD.mp3 est la meme app dans sa propre fenetre, avec un petit
renard pixel qui veille pendant les telechargements.

Installer : telechargez RENARD-setup.exe depuis la derniere release
GitHub et lancez-le. Pas de droits administrateur : l'app s'installe
dans %LOCALAPPDATA%\RENARD.mp3, avec yt-dlp, FFmpeg et Deno inclus
(rien a telecharger au premier lancement). Raccourcis sur le Bureau
et dans le menu Demarrer. Les fichiers arrivent dans
Telechargements\RENARD.mp3. Il faut le moteur Microsoft Edge
WebView2 (deja present sur Windows 10 / 11 a jour) : l'installateur
previent s'il manque.

Utiliser : collez un lien puis "Video" ou "MP3". Le bouton "plus..."
affiche tous les formats, l'onglet Convertir et les options.
Ctrl + M coupe ou remet le son.

Mise a jour : l'app verifie GitHub au lancement puis toutes les 12 h.
Quand une version existe, le renard tient un panneau
"nouvelle version" : un clic l'installe (apres les telechargements
en cours) et l'app redemarre seule.

Publier une nouvelle version (elisalien) : poussez un tag v2.x
(ex. git tag v2.0.1 && git push origin v2.0.1). Le workflow
"Release" compile RENARD.mp3.exe, l'installateur RENARD-setup.exe
et le zip de mise a jour RENARD-update.zip, et les joint a la
release. Le numero du tag devient la version de l'app.

Desinstaller : Parametres Windows > Applications > RENARD.mp3.
Les videos et musiques telechargees ne sont jamais supprimees.

Le reste de ce mode d'emploi concerne la version "dossier"
(launch.bat, interface dans le navigateur).

----------------------------------------------------------------
 INSTALLATION (une seule fois)
----------------------------------------------------------------

1. Double-cliquez sur  install.bat
   -> Il telecharge yt-dlp, FFmpeg et Deno dans le dossier "bin".
      Deno est le moteur JavaScript requis par YouTube.
   -> Si Windows SmartScreen apparait : "Informations complementaires"
      puis "Executer quand meme".
2. L'installation cree aussi le raccourci "yt-dlp Studio" sur le
   Bureau (clic droit -> Epingler a la barre des taches).
   S'il disparait : create-shortcut.bat le recree.

----------------------------------------------------------------
 UTILISATION
----------------------------------------------------------------

1. Double-cliquez sur  launch.bat  (ou le raccourci).
   -> L'interface s'ouvre dans le navigateur (Firefox en priorite).
   -> Une fenetre "yt-dlp Studio - serveur" s'ouvre REDUITE : c'est
      elle qui travaille. La fermer arrete les telechargements.

2. Onglet TELECHARGER
   - Collez vos liens (un par ligne), ou glissez un lien / un onglet
     sur le panneau.
   - Choisissez un format : Compatible (par defaut), Ultime, 4K, 2K,
     Full HD, HAP, HAP Q, MP3 ou Frames (une image PNG par frame).
   - Destination : bouton "Choisir..." (memorise).
   - Cliquez sur "Telecharger" (ou Ctrl + Entree).

   Rangement automatique :
   - Lien de playlist ou de chaine -> dossier au nom de la playlist,
     fichiers numerotes dans l'ordre.
   - Plusieurs liens d'un coup     -> sous-dossier "Lot <date heure>".
   - Un seul lien                  -> directement dans la destination.

3. Onglet CONVERTIR
   - Ajoutez un ou plusieurs fichiers : "Parcourir..." (selection
     multiple), chemin colle, ou bouton "Convertir ce fichier" sur un
     telechargement termine. Chaque fichier affiche resolution, duree,
     codecs et taille.
   - Format : MP4 H.264 / H.265, WebM VP9, ProRes 422, HAP, HAP Alpha,
     HAP Q, MP3, AAC, WAV, FLAC, GIF anime ou images PNG.
   - Reglages : qualite, largeur max, images par seconde, rotation,
     son (garder, normaliser, supprimer), debut / fin pour un extrait.
   - Sortie : a cote de chaque source ou dans un dossier choisi
     (ex. clip-h264.mp4, clip-hap.mov, dossier clip-frames).

4. La file d'attente affiche la progression, le temps restant,
   le journal et un bouton pour ouvrir le dossier.

5. Favori navigateur : Options avancees -> glissez le bouton
   "yt-dlp Studio" dans la barre de favoris. Sur une page video,
   cliquez-le : le lien arrive dans l'interface.

Mode manuel : Options avancees -> "Commande equivalente" -> Copier,
puis collez-la dans terminal.bat.

----------------------------------------------------------------
 MISE A JOUR DES OUTILS
----------------------------------------------------------------

Automatique au lancement (au plus une fois toutes les 12 h).
Pour forcer : double-cliquez sur  update.bat.
 - yt-dlp : canal nightly (suit les changements de YouTube).
 - Deno   : auto-mise a jour.
 - FFmpeg : re-telecharge UNIQUEMENT si une version plus recente existe.

Erreur 403 ou "caller does not have permission" : laissez "Cookies
du navigateur" active (Options avancees), avec Firefox connecte a
YouTube, puis relancez update.bat.
